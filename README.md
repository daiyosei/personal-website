# Ritabrata's Personal Website

The koi pond is implemented in typescript and the shader is from shader toy


Copyright Water Caustic Shader :
[Tileable Water Caustic by Dave Hoskins](https://www.shadertoy.com/view/MdlXz8)

## Development

Install dependencies with `npm install`, then start Vite:

```sh
npm run dev
```

## Production build

```sh
npm run build
```

Requires Node.js 18 or newer.
